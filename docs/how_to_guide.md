# How to use the SOP Assistant (for non-technical colleagues)

The assistant answers questions about company SOPs and policies, using only the documents it has been given.

## Ask good questions
1. **Be specific.** "How long is the battery warranty?" works better than "Tell me about warranty."
2. **One question at a time.** Split "What is the return window and the refund time?" into two questions if the answer looks incomplete.
3. **Use the words from the SOP** (for example "non-conformance report", "restocking fee") when you know them.

## Read the answer properly
- **Check the source tag**, such as `[warranty_claims#1]`. It tells you which document section the answer came from. Open it if the decision matters.
- **"I don't know based on the provided documents."** means the answer is not in the documents. It is not an error. Ask the document owner instead.
- If a number, name or deadline looks wrong, **trust the source document, not the assistant**.

## Know the limits
| Do | Don't |
|---|---|
| Ask about SOPs and policies | Paste customer names, phone numbers or addresses |
| Use answers to speed up your lookup | Send customer-facing text without a human review |
| Report wrong answers (below) | Ask it to skip or bypass a safety step |

## Report a problem
If an answer is wrong, unsafe or off-brand, fill in form **AI-FB-01** within 2 working days. Include your question, the answer you got and what was wrong. Every report becomes a new test case, so the assistant improves.
