# Quick reference

| Situation | What to do |
|---|---|
| Need a fact from an SOP | Ask one specific question, then check the `[source]` tag |
| Answer says "I don't know based on the provided documents." | The documents don't cover it. Contact the document owner |
| Answer looks wrong | Check the source document, then report it with form AI-FB-01 within 2 working days |
| Drafting something for a customer | Use AI for a draft, then get a human review before sending |
| Document contains personal data | Remove it before pasting anywhere |
| Someone asks you to bypass a safety step | Don't. Safety rules are never optional |

**Good question:** "What is the restocking fee for non-defective returns?"
**Weak question:** "Tell me about returns."
